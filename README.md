# youtube-bot
Este es un bot de Youtube para telegram, puede subir videos y audios
## Para ejecutar tu propio bot
1. git clone https://github.com/estevaofon/youtubebot.git
2. Instala las dependencias:
   - Windows (PowerShell): `py -m pip install -r requirements.txt`
   - macOS/Linux: `python3 -m pip install -r requirements.txt`
3. Obtén tu API_KEY con BotFather y configura la variable `TELEGRAM_BOT_TOKEN`:
   - En `.env`: `TELEGRAM_BOT_TOKEN=TU_TOKEN_AQUI`
4. Ejecuta el bot:
   - Windows: `py bot.py`
   - macOS/Linux: `python3 bot.py`

Pronto!
