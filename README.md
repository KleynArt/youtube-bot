# youtube-bot
Bot de descargas para Telegram. Permite bajar audio/video de YouTube y también descargar archivos desde enlaces directos.

## Cómo ejecutar tu propio bot
1. `git clone https://github.com/estevaofon/youtubebot.git`
2. `pip install -r requirements.txt`
3. Obtén un `TELEGRAM_TOKEN` con BotFather y colócalo en tu `.env` (o exporta la variable de entorno).
4. `python bot.py`

¡Listo!
